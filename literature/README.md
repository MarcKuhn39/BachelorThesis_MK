# Literature and Scientific Papers

This directory is for storing scientific papers, references, and research materials related to your bachelor thesis.

## Organization Suggestions

### By Topic
Create subdirectories for different research areas:
- `methodology/`
- `related-work/`
- `background/`

### By Source
Organize by publication venue or source:
- `journals/`
- `conferences/`
- `books/`
- `web-resources/`

## File Naming Convention
Consider using a consistent naming pattern:
- `AuthorYear_ShortTitle.pdf`
- Example: `Smith2023_MachineLearningReview.pdf`

## Citation Management
- Keep track of citation information
- Consider maintaining a bibliography file (`.bib` format)
- Include DOI or URL when available
