# BachelorThesis_MK

This repository is made to have a space where files can be shared between student and professor for the bachelor thesis.

## Directory Structure

### 📁 `current-documents/`
Contains the current status and versions of:
- **Exposé**: Latest versions of the thesis exposé
- **Thesis**: Current drafts and versions of the bachelor thesis

### 📁 `literature/`
Repository for scientific papers, references, and research materials:
- Research papers related to the thesis topic
- Academic references and citations
- Background reading materials

### 📁 `professor-files/`
Designated space for files shared by the supervising professor:
- Feedback documents
- Guidelines and requirements
- Meeting notes and administrative documents

## Usage Guidelines

- **Students**: Upload your work to `current-documents/` and relevant research to `literature/`
- **Professor**: Use `professor-files/` for sharing feedback, guidelines, and administrative materials
- Use clear, descriptive filenames with version numbers and dates
- Each directory contains a detailed README with specific organization tips

## Getting Started

1. Navigate to the appropriate directory for your file type
2. Review the directory-specific README for organization guidelines
3. Upload files using clear naming conventions
4. Keep the repository organized and up-to-date
