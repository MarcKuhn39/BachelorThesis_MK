# Professor Files

This directory is designated for files shared by the supervising professor.

## Purpose
- Feedback documents
- Guidelines and requirements
- Reference materials
- Meeting notes and agendas
- Evaluation rubrics
- Administrative documents

## Access
This directory is primarily for the professor to upload and organize files that need to be shared with the student during the thesis supervision process.

## Communication
Files placed here serve as a central location for document exchange between professor and student, ensuring all important materials are easily accessible and version-controlled.
